## What I'm building

### Text to ER

An AI-assisted workflow that transforms natural-language requirements into conceptual Entity-Relationship diagrams. The project explores how LLMs can identify entities, attributes, relationships, and cardinalities, then validate the resulting schema for structural consistency.

This work is part of my Computer Science research at the Federal University of Santa Catarina (UFSC).
